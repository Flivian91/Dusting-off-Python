# Project Name
Personal Study Session Checker
# What project does?
The project help the learner add, view, search compute total time taken to learn a certain concept. It acts as a centralized place to manage the student learning path.
# Concept Learnt
- Basic functions usage and reusability
- File handling 
- Advance input validation and data cleaning
- Error handling in file
- Usage of built in functions like enumerate(), divmod()
- Thinking like a programmer.
# How to run the project
1. Open the terminal
2. Navigate to the working directory using cd , where the main.py is located on day-02-expense-tracker
3. On the terminal run `python main.py`
