# Project name
Password Manager Prototype
# What project does?
The project help individuals to save there accounts credentials, Incase they forget they can refer
# Features Implemented.
1. Main menu - to select menu option
2. Add New account - to help the user add new account
3. View all accounts
4. Search by website name, Username or category
5. Update account using all available fields
6. Delete account using the account ID
7. Account Statistics
8. Sort accounts
9. Export account file
